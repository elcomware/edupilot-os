# Workspace behavior

- **Access.** Sign in with school ID, email and password. Keep the bearer token only in memory. Reloading or reopening the tab requires sign-in. A 401 clears the session and all cached school data. A protected deep link returns to its requested destination after sign-in. Sign out calls the server to revoke the token.
- **Navigation.** The module directory, its pins, preferences and module pages share one shell. Group, search and pin controls operate on the signed-in user's server-provided catalog. Do not use client preferences to grant access. The server is authoritative for permissions and school isolation.
- **Collections.** Both record editors use a native modal with labeled fields, an explicit save and cancel, pending actions, and retained values on failure. Student creation/editing accepts given and family names; archival requires a named confirmation and version. Workspace entries create titles and update title/status using a version. Conflicts keep the draft visible until the user chooses to load the latest record. No automatic write retries.
- **Results.** Show server-confirmed results, live feedback, and distinct loading, empty, forbidden, missing, conflict and error states. Page through server data. Only show actions permitted by the catalog and principal. Show no fake sample rows or derived financial/operational claims.
- **Preferences.** Locale, theme, accent, density, width and pinned modules are local cosmetic settings scoped to the current school and principal. Never persist records, credentials or tokens. System theme follows live OS changes. State may not survive device storage restrictions.
- **Accessibility.** Semantic links, buttons, headings, landmark navigation, skip link, visible focus and native selects. Modal dialogs contain focus and restore it; their action remains pending after a failure. Use localized live feedback and preserve a usable logical focus target after removal. At narrow sizes navigation reflows and table headings remain available. Respect reduced motion.
