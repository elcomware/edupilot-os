# Native dependency and browser-fixture qualification

This checkpoint tests the starter runtime. It does not certify the proposed group-tenancy runtime or a deployable release.

| Surface | Finding and change | Evidence |
|---|---|---|
| Go toolchain and module graph | Initial source scan reported 36 reachable advisories. Go minimum moved to 1.26.10 in native prerequisite checks, modules and Docker builder. Patched pgx, QUIC, x/net, OTel and gRPC; the intermediate compiled binary exposed GO-2026-6443 and gRPC was moved to 1.83.2. | `go mod verify` passed. `govulncheck@v1.9.0 ./...` and `govulncheck@v1.9.0 -mode=binary <api>` each reported **0 affected vulnerabilities**. Both also reported 1 imported-package and 4 module advisories outside detected call paths. Re-run on each release. |
| Goravel compatibility | The v1.18.0 telemetry log mapper uses an API removed in the fixed OTel family. Pinned the [upstream Goravel compatibility commit](https://github.com/goravel/framework/commit/2f75a1386784cb5e7e94230c2807afed05d89dce), version v1.18.1-0.20260811104128-2f75a1386784. Review this prerelease pin when upstream cuts a containing stable tag. | Official module checksum verified; upstream log instrumentation tests passed. Operators using explicit OTLP/HTTP trace or metric URLs should set the full signal path (for example /v1/traces); live exporter qualification needs an endpoint. |
| npm workspaces and browser tooling | glob/minimatch overrides and Vite/Vitest updates removed reported production and development findings. | Clean install, full root npm audit and isolated E2E package npm audit: **0 reported vulnerabilities**. Web: 14 tests and production build passed. Mobile: 9 tests, typecheck and both Expo JS exports passed. |
| Browser fixture login throttling | [Baseline Actions run](https://github.com/elcomware/edupilot-os/actions/runs/42140789673): both backend jobs passed, including PostgreSQL. Four of five end-to-end cases passed; preference reload failed on the ninth login to the shared account. | An isolated native API reproduced eight 200s followed by 429 using valid credentials. Assign separate random admin accounts per browser journey; capture only login HTTP status on failure. Production rate limits are unchanged. Three real API E2E cases passed locally on the patched stack. Browser retry needs a browser-capable host. |

The source and binary scans used the official Go vulnerability database. Results are observations at verification time, not a promise about future advisories. References: [Go security release history](https://go.dev/doc/devel/release), [gRPC advisory and fixed versions](https://pkg.go.dev/vuln/GO-2026-6443), [upstream OTel changelog](https://github.com/open-telemetry/opentelemetry-go/blob/v1.45.0/CHANGELOG.md).
